# Snail Traversal

## Problem Explanation
Add a `snail(rowsCount, colsCount)` method to Array prototype that arranges elements in a snail (zigzag column-first) pattern into a 2D matrix.

## How the Code Works
Fills the matrix column by column. Even-indexed columns fill top-to-bottom; odd-indexed columns fill bottom-to-top, creating the snail pattern.
